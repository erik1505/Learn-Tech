Guia da plataforma

Documentação

Visão geral das áreas do Learn Tech e dos principais fluxos de uso.

Acesso

Use a tela de autenticação para entrar ou criar uma conta. Sem o back-end, selecione “Acessar modo demonstração” para explorar a interface como professor, com dados locais de exemplo.

Turmas e atividades

  1. Abra “Turmas” para consultar ou criar uma turma.
  2. Selecione “Ver atividade” para abrir a trilha daquela turma.
  3. Na trilha, crie uma atividade ou abra o menu do card para editar e excluir.
  4. Abra uma atividade para consultar descrição, prazo, materiais e recursos disponíveis.

Learn Book e post-its

O painel do Learn Book reúne anotações e post-its. O texto é salvo automaticamente no armazenamento local do navegador; esses dados não são sincronizados entre dispositivos.

Recursos conectados

Login, notificações do sistema, envio de tarefas, notas e sincronização de dados dependem do back-end. No modo demonstração, o perfil e as alterações de turma e atividade são locais; ações que precisam do servidor não são enviadas.

Ajuda

Consulte as perguntas frequentes ou acesse o suporte.
