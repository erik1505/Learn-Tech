Perguntas frequentes

Respostas rápidas sobre acesso, turmas, atividades e anotações no Learn Tech.

Como acesso o sistema sem o back-end?

Na tela de autenticação, use “Acessar modo demonstração”. Uma sessão local de professor será aberta com uma turma e uma atividade de exemplo. Os dados de teste ficam salvos neste navegador.

Como abro as atividades de uma turma?

Acesse “Turmas” e use “Ver atividade” no card da turma. A lista de atividades é aberta para a turma selecionada.

Como crio ou edito uma atividade?

Na página de atividades, use “Nova atividade”. Para editar ou excluir, abra o menu de opções do card. No modo demonstração, essas alterações são locais.

Minhas notas e post-its são salvos?

As anotações do Learn Book e dos post-its são salvas automaticamente no armazenamento local do navegador. Limpar os dados do navegador pode removê-las.

Por que o login normal não funciona?

Cadastro, autenticação, notificações reais e operações sincronizadas precisam do back-end em execução. Para navegar pela interface sem ele, use o modo demonstração.

Ainda precisa de ajuda?

Entre em contato pela página de suporte.
